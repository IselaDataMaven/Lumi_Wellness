# Lumi Wellness 2.0

## Mission

Build a production-ready wellness application for people living with Fibromyalgia, chronic pain, anxiety and fatigue.

The application should feel premium, calming and accessible.

## Technology

- React
- TypeScript
- Vite

## Architecture

Use reusable components.

Do not duplicate code.

Use composition over repetition.

Keep components under 200 lines whenever possible.

## Accessibility

WCAG AA

Keyboard navigation

ARIA labels

Large touch targets

## Performance

Lazy load screens.

Optimize renders.

No unnecessary re-renders.

## Code Style

Strict TypeScript.

No any.

No inline styles.

No inline functions when avoidable.

Prefer hooks.

Reusable utilities.

## UX

Every interaction should feel calm.

Animations below 300ms.

Never block the user.

Avoid aggressive colors.

Use encouraging language.

## QA

Every feature must include:

✔ Error handling

✔ Loading state

✔ Empty state

✔ Responsive

✔ Accessibility

✔ Type safety
