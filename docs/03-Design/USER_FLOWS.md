# 1. Purpose

This document defines the main user journeys inside Lumi Wellness.

User flows describe how users move through the product to accomplish meaningful goals.

They help teams understand:

* User intentions
* Required screens
* Interaction points
* Success criteria
* Edge cases

---

# 2. User Flow Philosophy

Lumi Wellness flows should feel:

🌿 Natural

🤍 Supportive

✨ Simple

🌸 Personalized

The user should never feel lost.

Every flow should answer:

"What is the next helpful step?"

---

# 3. Flow Structure

Every user flow includes:

## User Goal

What the user wants to achieve.

## Entry Point

How the user starts.

## Steps

Actions and screens.

## Decisions

Possible paths.

## Success State

Completed experience.

## Recovery

What happens when something goes wrong.

---

# 4. Flow: New User Registration

## Goal

Create an account and begin a personalized wellness experience.

---

## Entry Point

User opens Lumi Wellness for the first time.

---

## Flow

```text
Open App

↓

Welcome Screen

↓

Create Account

↓

Verify Account

↓

Accept Privacy Preferences

↓

Start Onboarding

↓

Dashboard
```

---

## Screens

1. Welcome

2. Registration

3. Privacy Consent

4. Onboarding

5. Home Dashboard

---

## Success State

User reaches a personalized Lumi experience.

---

## Principles

Do:

✔ Explain why information is requested

✔ Keep steps short

✔ Allow returning later

Avoid:

✘ Long forms

✘ Unclear permissions

---

# 6. Flow: Daily Emotional Check-In

## Goal

Help users recognize their emotional state.

---

## Entry Point

Home Dashboard

---

## Flow

```text
Daily Check-In Card

↓

Select Mood

↓

Optional Reflection

↓

AI Response

↓

Suggested Activity
```

---

## Decisions

If user feels positive:

↓

Suggest growth activities

---

If user feels overwhelmed:

↓

Offer calming resources

---

If user requests help:

↓

Provide appropriate support guidance

---

## Rules

The check-in:

* Is optional
* Has no judgment
* Does not create failure states

---

# 7. Flow: AI Companion Conversation

## Goal

Allow users to receive personalized support.

---

## Flow

```text
Open Lumi AI

↓

User Message

↓

AI Response

↓

Suggested Options

↓

User Chooses Next Step
```

---

## AI Response Structure

1. Acknowledge

2. Support

3. Suggest

4. Offer choice

---

Example:

```text
"I hear that today feels difficult.

Would you like to try a short breathing exercise
or write about what happened?"
```
