# 1. Purpose

This document defines the typography system for Lumi Wellness.

Typography should create an experience that feels:

🌿 Calm

🤍 Readable

✨ Human

🌸 Approachable

The typography system establishes consistency across:

* Mobile applications
* Web platforms
* AI conversations
* Educational content
* Journaling experiences

---

# 2. Typography Philosophy

Typography is not decoration.

It communicates:

* Importance
* Emotion
* Hierarchy
* Personality

Lumi Wellness uses typography to reduce cognitive effort and create comfortable reading experiences.

---

# 3. Font Principles

Fonts should be:

✔ Highly readable

✔ Friendly

✔ Accessible

✔ Comfortable for long sessions

Avoid:

✘ Decorative fonts for body text

✘ Excessive font variations

✘ Dense text blocks

---

# 4. Font Families

## Primary Font

Used for:

* Headings
* Navigation
* Buttons
* Important messages

Characteristics:

* Modern
* Rounded
* Friendly
* Clean

Recommended:

```text
Inter
Nunito Sans
Plus Jakarta Sans
```

Token:

```text
font-family-primary
```

---

## Secondary Font

Used for:

* Journal entries
* Long-form content
* Reflections

Characteristics:

* Comfortable reading
* Good spacing
* Human feeling

Recommended:

```text
Source Sans 3
Open Sans
```

Token:

```text
font-family-secondary
```

---

## Monospace Font

Used only for:

* Technical information
* Developer documentation
* Data displays

Token:

```text
font-family-mono
```

---

# 5. Type Scale

Lumi Wellness follows a clear hierarchy.

| Style      |  Size | Weight | Usage             |
| ---------- | ----: | -----: | ----------------- |
| Display    | 48 px |    700 | Hero messages     |
| H1         | 36 px |    700 | Main page titles  |
| H2         | 30 px |    600 | Section titles    |
| H3         | 24 px |    600 | Card titles       |
| H4         | 20 px |    500 | Subsections       |
| Body Large | 18 px |    400 | Important reading |
| Body       | 16 px |    400 | Standard text     |
| Body Small | 14 px |    400 | Supporting text   |
| Caption    | 12 px |    500 | Metadata          |

---

# 6. Font Weight System

Use only defined weights.

| Token           | Value | Usage     |
| --------------- | ----: | --------- |
| weight-regular  |   400 | Body      |
| weight-medium   |   500 | Labels    |
| weight-semibold |   600 | Subtitles |
| weight-bold     |   700 | Titles    |

Avoid unnecessary weights.

---

# 7. Line Height

Comfortable reading requires generous spacing.

## Headings

```text
1.2 ratio
```

Example:

36 px font

44 px line height

---

## Body Text

```text
1.5 ratio
```

Example:

16 px font

24 px line height

---

## Long Reading Content

```text
1.6 ratio
```

Example:

18 px font

29 px line height

---

# 8. Letter Spacing

Default:

```text
0
```

Small text:

```text
+0.02em
```

Uppercase labels:

```text
+0.05em
```

Avoid excessive spacing.

---

# 9. Text Colors

Typography must use semantic color tokens.

Primary text:

```text
color-text-primary
```

Secondary text:

```text
color-text-secondary
```

Disabled text:

```text
color-disabled
```

Never use random colors.

---

# 10. Content Width

For comfortable reading:

Maximum line length:

75 characters

Ideal:

50-75 characters

---

# 11. Mobile Typography

Mobile screens prioritize readability.

Rules:

* Minimum body text: 16 px
* Avoid long paragraphs
* Increase spacing between sections
* Use clear hierarchy

---

# 12. AI Conversation Typography

AI messages should feel conversational.

Rules:

Use:

* Short paragraphs
* Clear spacing
* Friendly language

Avoid:

* Large walls of text
* Technical language
* Overwhelming explanations

Example:

Good:

```
You made time for yourself today.

That matters. 🌿

Would you like to continue?
```

Avoid:

```
Your behavioral wellness metrics indicate
a positive improvement trajectory...
```

---

# 13. Journal Typography

Personal writing areas should feel intimate.

Recommendations:

* Larger reading size
* Comfortable line height
* Minimal distractions

Suggested:

Body:

18 px

Line height:

1.6

---

# 14. Accessibility

Typography must support:

✔ Dynamic text scaling

✔ Zoom up to 200%

✔ Screen readers

✔ Clear hierarchy

✔ Sufficient contrast

---

# 15. Typography Checklist

Before releasing a screen:

□ Clear hierarchy

□ Readable body text

□ Correct font weights

□ Proper line height

□ Mobile tested

□ Dark mode tested

□ Accessibility checked
