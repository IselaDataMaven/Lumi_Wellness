# 🌸 Lumi Wellness Design System

> **Designing with Compassion**

**Version:** 1.0.0

**Project:** Lumi Wellness

**Status:** Living Document

**Owner:** Isela L. García

---

# 1. Introduction

Lumi Wellness is a digital wellness platform designed to support people living with chronic pain, with a special focus on women living with fibromyalgia.

This Design System defines the visual language, interaction principles, and communication guidelines that ensure a consistent, accessible, and human-centered experience across the entire product.

This document is not intended to limit creativity.

Its purpose is to preserve the identity of Lumi Wellness while allowing the product to evolve over time.

---

# 2. Design Philosophy

Before designing any interface, every team member should answer one question:

> **Does this decision help our users feel understood?**

If the answer is no, the solution should be reconsidered.

We don't simply design interfaces.

We design experiences.

---

# 3. Design Principles

## 3.1 Design with Empathy

Every interaction should communicate kindness, respect, and understanding.

Never guilt.

Never pressure.

Never create anxiety.

---

## 3.2 Design for Calm

Every screen should reduce cognitive load.

We prefer generous whitespace over crowded interfaces.

Simplicity creates confidence.

---

## 3.3 Design to Last

We don't chase design trends.

We build a timeless system capable of evolving for years without losing its identity.

---

## 3.4 Design for Everyone

Accessibility is not an enhancement.

Accessibility is part of the design process from day one.

---

## 3.5 Design with Honesty

Lumi Wellness is not a medical product.

We never provide medical diagnoses.

We never replace healthcare professionals.

We communicate our limitations transparently.

# 5. Voice & Tone

Every piece of text inside Lumi Wellness should sound natural, supportive, and encouraging.

### Preferred

"How is your body feeling today?"

Instead of

"Pain Level"

---

"Welcome back."

Instead of

"You lost your streak."

---

"It's okay to rest."

Instead of

"You didn't complete today's routine."

---

Language should always encourage, never shame.

---

# 6. Visual Principles

Every visual decision should communicate:

🌿 Calm

🌸 Trust

🤍 Clarity

💜 Hope

---

General Rules

• Use generous whitespace

• Keep interfaces clean

• Minimize visual noise

• Prioritize readability

• Use simple iconography

• Keep animations subtle

---

# 7. Minimal Design

Every element must have a purpose.

If a component does not add value to the user's experience, it should be removed.

Less interface.

More clarity.

---

# 8. Color System

Our color palette is inspired by nature, wellness, and emotional balance.

| Color | Purpose |
|--------|---------|
| Sage | Balance |
| Lavender | Calm |
| Rose | Compassion |
| Ivory | Comfort |
| Sky | Trust |

Colors may evolve over time while preserving Lumi Wellness' identity.

---

# 9. Typography

Typography should be:

• Modern

• Light

• Highly readable

• Friendly

Decorative fonts should never be used for body content.

---

# 10. Spacing System

Use a consistent spacing scale.

```
4
8
12
16
24
32
48
64
```

All layouts and components must follow this spacing system.

---

# 11. Border Radius

Components should use soft rounded corners.

Never completely sharp.

Never excessively rounded.

---

# 12. Shadows

Shadows should create subtle depth.

Never become the visual focus.

Less is more.

---

# 13. Iconography

Icons should be:

• Simple

• Recognizable

• Consistent

• Minimal

Avoid excessive visual detail.

---

# 14. Motion

Motion should feel natural and calm.

Recommended durations

• 150 ms

• 250 ms

• 350 ms

Animations should support the experience, never distract from it.

---

# 15. Accessibility

Every component must comply with WCAG 2.2 AA guidelines.

Required support:

✔ Keyboard Navigation

✔ Screen Readers

✔ Visible Focus States

✔ Accessible Color Contrast

✔ 200% Zoom

✔ Dark Mode

Accessibility is a product requirement, not an optional feature.

---

# 16. Responsive Design

Lumi Wellness is designed as one adaptive system.

Supported devices:

• Mobile

• Tablet

• Desktop

We do not create separate products.

We create one responsive experience.

---

# 17. Components

Every reusable component must follow five principles:

• Consistency

• Reusability

• Accessibility

• Documentation

• Testability

---

# 18. Component States

Every component must support the following states:

• Default

• Hover

• Focus

• Active

• Disabled

• Loading

• Error

• Success

• Empty

No component should be considered complete until all states are documented.

---

# 19. Evolution

This Design System is a living document.

It will continue evolving as Lumi Wellness grows.

Changes should only be introduced when they improve the user experience.

Visual trends alone are never a valid reason for redesign.

Every evolution must preserve the identity and purpose of Lumi Wellness.

---

# 20. Our Commitment

Lumi Wellness exists to support people.

Not to judge them.

Not to pressure them.

Not to compete with them.

Every line of code.

Every illustration.

Every interaction.

Every screen.

Should remind us that there is a real person behind every tap.

If a technical decision improves performance but makes users feel less understood,

it does not belong in Lumi Wellness.
