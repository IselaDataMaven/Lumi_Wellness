# 1. Purpose

This document defines how empty states should be designed across Lumi Wellness.

An empty state appears when content, data, or activity does not exist yet.

Empty states should never feel like missing content.

They should guide users toward their next meaningful step.

---

# 2. Empty State Philosophy

An empty state is an opportunity to:

🌿 Explain

🤍 Encourage

✨ Guide

🌸 Connect

The user should feel:

"Something is waiting for me here."

Not:

"Something is broken."

---

# 3. Empty State Structure

Every empty state should include:

## 1. Illustration or Visual Element

A calm and meaningful visual.

Purpose:

* Create emotional connection
* Explain the situation

---

## 2. Title

Short and clear.

Examples:

"Your journal is ready"

"Your journey begins here"

---

## 3. Description

Explain what is happening.

Keep it:

* Simple
* Supportive
* Brief

---

## 4. Primary Action

Help users continue.

Examples:

* Start Journal
* Create Goal
* Try Activity

---

## 5. Optional Secondary Action

Provide alternatives when useful.

Examples:

* Explore Activities
* Learn More

---

# 4. Empty State Principles

## Be Helpful

Never leave users without direction.

Bad:

"No entries."

Good:

"Your reflections will appear here after you write your first journal entry."

---

## Be Positive

Avoid language that suggests failure.

Bad:

"You haven't completed anything."

Good:

"Your wellness journey is waiting for its first step."

---

## Be Clear

Users should understand:

* Why the state exists
* What they can do next

---

# 5. Common Empty States

---

# Journal Empty State

## Situation

User has no journal entries.

---

Example:

```text
🌸 Your thoughts have a place here.

Write your first reflection and create a space for yourself.

[Write First Entry]
```

---

# Activities Empty State

## Situation

No recommended activities available.

---

Example:

```text
🌿 Discover your next moment of care.

Explore activities designed to support your wellness journey.

[Explore Activities]
```

---

# Goals Empty State

## Situation

User has not created goals.

---

Example:

```text
✨ Start with a small intention.

Choose something meaningful you would like to focus on.

[Create Goal]
```

---

# Progress Empty State

## Situation

Not enough activity history exists.

---

Example:

```text
🌱 Your progress will appear here.

Every small moment of self-care becomes part of your journey.

[Start Activity]
```

---

# AI Conversation Empty State

## Situation

No previous conversations.

---

Example:

```text
🤍 Lumi is here whenever you need a moment to reflect.

What would you like to talk about today?

[Start Conversation]
```

---

# 6. Empty State Types

## First Use

User has never used a feature.

Goal:

Introduce and guide.

---

## No Data Yet

Information will appear after activity.

Goal:

Explain future value.

---

## No Results

Search or filter returns nothing.

Goal:

Help users adjust.

---

## Offline State

Content cannot load.

Goal:

Explain limitation and provide recovery.

---

# 7. Visual Guidelines

Empty state illustrations should feel:

✔ Soft

✔ Calm

✔ Hopeful

✔ Inclusive

Avoid:

✘ Medical imagery

✘ Warning visuals

✘ Sad or alarming illustrations

---

# 8. Actions

Primary actions should:

* Move the user forward
* Be specific
* Use Lumi voice

Good:

"Start Reflection"

Avoid:

"Submit"

"Continue"

when the action is unclear.

---

# 9. Accessibility

Every empty state must support:

□ Screen readers

□ Clear headings

□ Descriptive buttons

□ Sufficient contrast

□ Keyboard navigation

---

# 10. Empty State Checklist

Before release:

□ Purpose is clear

□ Explanation exists

□ Next action exists

□ Tone matches Lumi

□ Illustration supports meaning

□ Accessibility reviewed

□ Mobile layout tested

□ Dark mode considered

---

# 11. Future Evolution

Empty states may evolve with:

* Personalized illustrations
* AI-generated encouragement
* Adaptive recommendations

Every empty state should preserve:

Calm

Clarity

Connection
