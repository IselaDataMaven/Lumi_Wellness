# 1. Purpose

This document defines reusable UX patterns for Lumi Wellness.

UX patterns are proven interaction solutions that help users complete tasks in a consistent and intuitive way.

They define:

* User goals
* Interaction behavior
* Interface structure
* Expected outcomes

---

# 2. UX Pattern Philosophy

Lumi Wellness experiences should feel:

🌿 Simple

🤍 Supportive

✨ Predictable

🌸 Human

Users should always understand:

* What is happening
* Why it matters
* What they can do next

---

# 3. Pattern Structure

Every UX pattern should include:

## User Goal

What the user wants to achieve.

## Context

When the pattern appears.

## Flow

Steps required.

## Interface Elements

Components involved.

## Success State

What completion looks like.

## Edge Cases

Possible problems.

---

# 4. Pattern: Emotional Check-In

## Purpose

Allow users to quickly express their current emotional state.

---

## User Goal

"I want to understand how I feel today."

---

## Flow

```
Open Check-In

↓

Select emotional state

↓

Add optional reflection

↓

Receive supportive response

↓

Continue wellness activity
```

---

## Interface Elements

Uses:

* Mood Selector
* Text Input
* AI Companion
* Recommendation Card

---

## Example

```
How are you feeling today?

😊 Great

🙂 Good

😐 Neutral

😔 Difficult

😢 Very difficult
```

---

## Rules

Do:

✔ Allow skipping

✔ Avoid judgment

✔ Keep interaction short

Don't:

✘ Force daily completion

✘ Create scores that judge emotions

---

# 5. Pattern: Wellness Activity Completion

## Purpose

Guide users through wellness exercises.

Examples:

* Breathing
* Meditation
* Reflection

---

## Flow

```
Choose Activity

↓

View Introduction

↓

Complete Exercise

↓

Receive Feedback

↓

Save Progress
```

---

## Interface Elements

Uses:

* Activity Card
* Progress Indicator
* Timer
* Completion Message

---

## Completion Example

Good:

"Nice work taking a moment for yourself 🌿"

Avoid:

"You completed your task."

# 6. Pattern: Personal Journal

## Purpose

Provide a safe space for reflection.

---

## Flow

```
Open Journal

↓

Write Reflection

↓

Save Entry

↓

View History
```

---

## Design Rules

The journal should feel:

* Private
* Calm
* Personal

Avoid:

* Character limits that create pressure
* Performance metrics
* Comparison

---

Help users create sustainable routines.

---

## Philosophy

Progress over perfection.

---

## Flow

```
Choose Habit

↓

Define Goal

↓

Track Progress

↓

Reflect

↓

Adjust
```

---

## Avoid

❌ Punishing missed days

❌ Competitive rankings

❌ Negative streak messages

---

## Flow

```

↓

AI Understanding

Supportive Response

↓

↓

# 9. Pattern: Recommendations

## Purpose

Suggest personalized wellness activities.

---

## Recommendation Structure

```
Context

↓

Suggestion

↓

Reason

↓

Optional Action
```

Example:

"Your check-in shows you may need a quiet moment.

Would you like to try a 2-minute breathing exercise?"

# 10. Pattern: Progress Visualization

## Purpose

Show personal growth.

---

## Rules

"I am learning."

Not:

"I am competing."

---

Use:

✔ Milestones

✔ Reflections

✔ Personal history

Avoid:

✘ Rankings

✘ Comparison

✘ Pressure metrics

---

Optional action
```

# 12. Pattern: Error Recovery

## Purpose

Help users continue after problems.

---

Flow:

```
Problem

↓

Explanation

↓

Solution

↓

Continue
```

---

Example:

"We couldn't save your journal entry.

Your text is still here. Try again."

---

# 15. UX Pattern Checklist

Before creating a new experience:

□ User goal is clear

□ One primary action exists

□ Emotional impact considered

□ Accessibility supported

□ Empty states defined

□ Error states defined

□ Success state defined
