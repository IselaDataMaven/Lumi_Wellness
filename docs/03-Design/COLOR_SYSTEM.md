# 1. Purpose

This document defines the color system for Lumi Wellness.

Colors are used to:

* Create emotional connection
* Improve usability
* Communicate status
* Establish visual hierarchy
* Support accessibility

Color should guide the user, never overwhelm them.

---

# 2. Color Philosophy

Lumi Wellness uses colors inspired by:

🌿 Nature

✨ Light

🌸 Emotional balance

🤍 Calm environments

The color system should feel:

* Warm
* Safe
* Optimistic
* Peaceful

# 6. Color Usage Rules

## Do:

✔ Combine colors with text labels

✔ Maintain contrast

✔ Use color intentionally

✔ Reserve strong colors for important moments

---

## Don't:

✘ Use color as the only status indicator

✘ Create excessive colorful screens

✘ Use red for normal feedback

✘ Use bright colors that increase anxiety

# 9. Accessibility Requirements

All colors must comply with:

WCAG AA contrast requirements.

Minimum:

Normal text:

4.5:1

Large text:

3:1
