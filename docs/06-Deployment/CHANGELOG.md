# Versioning Strategy

Lumi Wellness follows Semantic Versioning:

```text id="7s9c4d"
MAJOR.MINOR.PATCH
```

Example:

```text id="q8m2pv"
1.2.3
```

Meaning:

* MAJOR → Breaking changes
* MINOR → New features
* PATCH → Bug fixes

# Release Checklist

Before publishing a release:

□ Version updated

□ Changes documented

□ Tests completed

□ Documentation updated

□ Security reviewed

□ Deployment verified

# Documentation Rules

Every important product change should include:

* Clear explanation
* User impact
* Technical impact when relevant

Avoid:

* Internal-only descriptions
* Unclear technical notes
* Missing context
