# 1. Purpose

This document defines the user stories that guide Lumi Wellness development.

User stories describe:

* Who the user is
* What they need
* Why it matters

They help transform user needs into meaningful product experiences.

---

# 2. User Story Format

Lumi Wellness follows this structure:

```text
As a [user]

I want to [action]

So that [benefit]
```

Example:

```text
As a user,

I want to track how I feel each day,

So that I can understand my personal patterns.
```

---

# 3. Product Story Principles

Every user story should:

* Solve a real user need
* Have a clear value
* Be understandable
* Support accessibility
* Respect user autonomy

---

# 4. Onboarding Stories

---

## US-001 — Welcome Experience

### Story

As a new user,

I want to understand what Lumi Wellness offers,

So that I feel comfortable starting my journey.

### Acceptance Criteria

□ Clear introduction

□ Friendly language

□ No overwhelming information

□ User understands next step

---

## US-002 — Personal Preferences

### Story

As a user,

I want to personalize my experience,

So that Lumi feels relevant to my needs.

### Acceptance Criteria

□ Preferences can be selected

□ Options are understandable

□ User can change preferences later
